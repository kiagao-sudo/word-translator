# 🔤 单词翻译器

一个简单好用的在线单词翻译工具，支持实时翻译、历史记录、一键复制等功能。

## ✨ 功能特性

- 🌐 实时翻译英文单词到中文
- 📜 自动保存翻译历史（最近 10 条）
- 📋 一键复制翻译结果
- 🎨 美观的 UI 界面
- 📱 响应式设计，手机电脑都能用
- 🔒 纯前端实现，数据保存在本地

## 🚀 快速开始

### 方式一：直接打开
双击 `index.html` 即可使用

### 方式二：部署到线上
查看 [DEPLOY.md](./DEPLOY.md) 获取部署指南
